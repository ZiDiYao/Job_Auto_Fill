Employer-friendly defaults

These are deterministic answers, not AI guesses. Choose Always ask me for anything that is not true. The extension never submits the application, so all answers remain available for review.

Resume upload

Your Docker backend supplies the saved resume and the extension keeps a browser-local cache for attachment to application pages. It is never uploaded anywhere except the application page you opened and the configured AI provider when its text is required as evidence.

No resume saved

Adaptive AI

Unanswered open-ended questions can be drafted by the local backend using DeepSeek, or by an optional local Ollama model. The model receives CV evidence and job context. Saved demographic and legal answers are included for structured-field mapping only when the separate permission below is enabled. AI-filled fields are marked purple and must be reviewed before submission.

Custom question rules

Add repetitive questions as JSON. match is a case-insensitive regular expression tested against the field label; value is what should be entered. Custom rules override built-in mappings.

Example rules 
[
  { "match": "available.*start|start date", "value": "January 2027" },
  { "match": "length.*work term|co-?op duration", "value": "8 months" },
  { "match": "how did you hear", "value": "Company website" }
]

Optional self-identification

Enter the wording you normally select, such as Prefer not to answer, No, or the identity shown by the application portal. Matching is case-insensitive and works with native dropdowns, radio buttons, and common checkbox groups. Blank values are never filled.
